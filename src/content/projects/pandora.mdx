### Concept

Inspired by the *Revenge* TV show's [Infinity Box](http://revengeabc.wikia.com/wiki/Infinity_Box) — a physical repository of memories — Pandora is a collector's box that digitizes the faces from photographs placed inside it. Slip in an old photo; the box extracts every face and uploads it to the cloud where it's accessible from any device.

The goal was a finished, polished object: not a breadboard in a shoebox, but something that looked like it belonged on a shelf.

### Electronics First

The two hardest technical pieces went first: getting live snapshots from the webcam, and sending extracted faces over WiFi to a cloud service.

<ProcessImage src="/projects/pandora/webcam_testing.jpg" alt="Laptop screen showing live webcam feed being transmitted to a Node.js web service" caption="First milestone — streaming live video over WiFi to a Node.js web service running locally. Once this worked, I added OpenCV face detection to send only extracted faces." />

With that working, I installed OpenCV on the Intel Edison, implemented face detection and cropping, and wired up the full pipeline: photo in → face detected → cropped face uploaded to Azure-hosted Node.js service → accessible from any browser.

<ProcessImage src="/projects/pandora/breadboard.jpg" alt="Intel Edison connected to a breadboard with buttons and LEDs wired up" caption="Edison on breadboard. I needed a trigger button (camera shutter), a reset button, a progress LED for OpenCV computation and WiFi transfer, and an RGB LED indicating good vs. bad memory state." />

<ProcessImage src="/projects/pandora/interaction.jpg" alt="Hand-drawn sketch of the box interaction: photo goes in, face comes out to the cloud" caption="Interaction sketch. The entire surface interaction is just: open box, place photo, press button." />

### Building the Box

I used InkScape to design laser-cut plywood sides with **box joints** — interlocking tabs that snap together without glue, relying entirely on friction. The cut files went straight to a laser cutter.

### Stack

- **Intel Edison** — main compute, runs OpenCV face detection
- **OpenCV** — face detection and extraction
- **Node.js / Azure** — cloud service receiving, storing, and serving face images
- **InkScape + laser cutter** — box panels and joints
